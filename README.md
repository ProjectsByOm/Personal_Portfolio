# Your Name — Portfolio

A dark, developer-inspired personal portfolio built with plain HTML, CSS, and JavaScript. Each section has its own static route and works on GitHub Pages without a build step.

## Routes

- `/` — Home
- `/about/` — About Me
- `/education/` — Education
- `/skills/` — Skills
- `/projects/` — Projects
- `/achievements/` — Achievements & Certifications
- `/experience/` — Experience
- `/contact/` — Contact, LinkedIn, and GitHub

Each route is an `index.html` inside its matching folder. Shared styles and navigation behavior live in `style.css` and `script.js` at the repository root.

## Personalize before publishing

Search the HTML files for `Your Name`, `yourusername`, `your.email@example.com`, `20XX`, and other starter prompts. Replace these with accurate details, remove sections or entries that do not apply, and add real links for projects and certifications. Update each page's title and description if you change the portfolio name.

## Preview locally

Open `index.html` in a browser, or use VS Code Live Server (or another static file server) from the repository root. No dependencies or build tools are required.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the published URL shown in Pages settings. Folder routes such as `/projects/` are served from each folder's `index.html`.
